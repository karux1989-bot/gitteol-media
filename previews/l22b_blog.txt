# 제목
워드 한글 변환 무료로, docx hwp 변환·webp jpg 변환까지 폴더에 넣으면 끝 | Filee 사용 방법

# 본문

워드 파일을 한글로 바꾸려고, 검색해서 나온 아무 변환 사이트에 문서를 올려 본 적 있죠?

오늘 소개할 건 파일을 다른 형식으로 바꿔 주는 무료 변환 앱, Filee예요. 윈도우 PC에 받아서 직접 써 봤어요. 시험에 쓴 회의록과 사진은 모두 시험용으로 만든 가짜 파일이에요.

[사진 1: 01_엔진선택나중에 (filee/cap/c01_engine.png)]
↑ 처음 켜면 나오는 "변환 엔진 선택" 창이에요

■ 어떤 앱이에요?

파일을 다른 형식으로 바꿔 주는 변환 앱이에요. 무료이고, 깃허브 저장소(KnifeLemon/Filee)에 코드가 공개돼 있어요(MIT 라이선스). 깃허브 별 28,793을 받았어요(2026년 11월 19일 확인). 이번에 쓴 버전은 2.5.0이에요.

- 메뉴가 한국어로 나와요
- 폴더 하나를 정해 두면, 거기 넣은 파일이 자동으로 바뀌어요
- 워드 파일(.docx)을 한글 파일(.hwp)로도 바꿔요
- 설명서(README)에는 파일을 어디에도 올리지 않는다고 적혀 있어요

■ 직접 해봤어요 STEP 1 · 설치하고 처음 켜기

윈도우에서는 명령 프롬프트에 아래 한 줄을 넣어 설치할 수 있어요.

winget install --id KnifeLemon.Filee

깃허브 Releases 에서 설치 파일이나 휴대용(Portable) zip 을 받아도 돼요. 이번 시험은 휴대용 zip 으로 했어요. 받은 zip 의 SHA256 값이 공식 값과 같은 것도 확인했어요. winget 은 목록에 Filee 가 있는 것까지만 확인했고, 설치할 때 관리자 권한 창이 떠요.

처음 켜면 "변환 엔진 선택" 창이 떠요. 이미지·PDF·오피스 문서·HWP·전자책·압축 파일·글꼴·CAD·3D 모델은 지금 바로 변환된다고 나와요. 동영상·오디오 같은 형식은 필요할 때 엔진을 받으면 돼요. 저는 "나중에"를 눌러 넘어갔어요.

■ 직접 해봤어요 STEP 2 · 자동 변환 폴더 만들기 (webp → JPG)

왼쪽 메뉴에서 "자동 변환 폴더"를 누르고 "+ 폴더 추가"를 눌렀어요. 감시할 폴더 경로를 넣고, 변환할 프리셋을 JPG 로 골랐어요. 위쪽 스위치가 "감시 중"으로 켜져 있으면 준비 끝이에요.

그 폴더에 webp 사진 2장을 넣었어요. 그러니 폴더 안에 converted 폴더가 생기고, 거기에 JPG 2장이 생겼어요. 화면 아래 최근 결과에는 "2개 변환, 실패 없음"이라고 나왔어요. 넣었던 webp 원본은 그대로 남아 있었어요.

[사진 2: 02_자동변환폴더JPG (filee/cap/c03_watch_done.png 자른 것)]
↑ 감시할 폴더와 프리셋 JPG 를 정해 두니, 아래에 "2개 변환, 실패 없음"이 나왔어요 (경로는 시험 폴더예요)

■ 직접 해봤어요 STEP 3 · 워드 → 한글(HWP) 바꾸기

이번엔 같은 폴더에서 변환할 프리셋을 HWP 로 바꿨어요.

[사진 3: 03_프리셋HWP (filee/cap/c05_hwp_done.png 자른 것)]
↑ 변환할 프리셋을 HWP 로 바꾼 화면이에요

그리고 워드로 만든 회의록(meeting_notes.docx)을 폴더에 넣었어요. 그러니 converted 폴더에 meeting_notes.hwp 가 생겼어요.

내용이 제대로 들어갔는지 보려고, 만든 HWP 파일을 다시 TXT 와 PNG 로 바꿔 봤어요. "주간 회의 정리"로 시작하는 회의록 내용이 그대로 들어 있었어요.

[사진 4: 04_변환된회의록 (filee/check/meeting_notes.png 자른 것)]
↑ 바꾼 HWP 파일을 다시 그림으로 바꿔 본 거예요. 회의록 내용이 그대로예요

■ 직접 해봤어요 STEP 4 · 홈에서 최근 변환 기록 보기

홈 화면에는 바꾼 기록이 남아요. HWP 로 바꾼 회의록, JPG 로 바꾼 사진 2개가 목록에 있었어요. 기록마다 파일 열기 · 폴더 열기 · 되돌리기 버튼이 있어요. 되돌리기 버튼은 있는 것만 확인했고, 눌러 보지는 않았어요.

[사진 5: 05_최근변환기록 (filee/cap/c07_home_recent.png 자른 것)]
↑ 홈 화면의 최근 변환 목록이에요

■ 원형 툴바도 있어요

설정의 "원형 툴바" 화면에서 HWP/HWPX 파일용 형식 바퀴를 봤어요. 바퀴에는 PDF·DOCX·HWPX·HWP·PNG·TXT 가 들어 있어요. 설명서에 따르면 탐색기에서 Ctrl 키를 누른 채 파일을 끌면 커서 옆에 이 바퀴가 뜬다고 해요. 이 Ctrl 끌기는 이번에 직접 해 보지 않았어요.

[사진 6: 06_원형툴바HWP (filee/cap/c08_wheel_hwp.png 자른 것)]
↑ 원형 툴바 설정 화면의 HWP/HWPX 바퀴예요

■ 쓰는 방법

1. 설치: winget install --id KnifeLemon.Filee 또는 깃허브 Releases 에서 설치 파일·휴대용 zip 받기
2. 처음 켜면 나오는 "변환 엔진 선택" 창에서 "나중에"
3. 자동 변환 폴더 → + 폴더 추가 → 감시할 폴더 경로 넣기
4. 변환할 프리셋 고르기 (사진은 JPG, 워드 → 한글은 HWP)
5. 그 폴더에 파일 넣기 → converted 폴더에서 바뀐 파일 확인
6. 홈 화면에서 최근 변환 기록 보기

■ 무료예요?

- 무료예요. MIT 라이선스이고 깃허브에 코드가 공개돼 있어요
- 설명서 기준으로 윈도우 10·11, 맥(미리보기), 리눅스용이 있어요

■ 알아 둘 점

- 시험에 쓴 회의록·사진은 시험용으로 만든 가짜 파일이에요
- 동영상·오디오 변환은 엔진을 따로 받아야 해요. 이번에는 엔진 설치와 동영상·오디오 변환은 해 보지 않았어요
- "파일을 어디에도 올리지 않는다"는 건 설명서(README)에 적힌 내용이에요. 인터넷을 끊고 따로 시험해 보지는 않았어요
- 되돌리기 버튼과 Ctrl 끌기 형식 바퀴는 이번에 직접 써 보지 않았어요

■ 이런 분께 추천해요

- 워드 파일을 한글 파일로 자주 바꿔야 하는 분
- 받은 webp 사진을 JPG 로 바꾸는 일이 잦은 분
- 변환 사이트에 문서를 올리는 게 마음에 걸리던 분
- 무료 파일 변환 프로그램을 찾는 분

■ 한 줄 정리

폴더 하나 정해 두면, 넣는 파일이 알아서 JPG·한글 파일로 바뀌어요.

화면 출처: 윈도우 PC에서 직접 써 봤어요 (회의록·사진은 시험용 가짜 파일)
