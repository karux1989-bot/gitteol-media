- [타겟 검색 의도] 워드(docx) 파일을 한글(hwp)로, webp 사진을 jpg로 무료로 바꾸는 방법 찾기

직접 써 본 결과 (2026-11-19, 윈도우 PC, 시험용 가짜 파일)
- 설치: 윈도우 `winget install --id KnifeLemon.Filee` 또는 깃허브 Releases 설치 파일·휴대용(Portable) zip. 버전 2.5.0
- 시험은 휴대용 zip(공식 SHA256 대조 일치)으로 함. winget 은 목록에 있는 것만 확인(설치 때 관리자 권한 창이 뜸)
- 첫 실행 "변환 엔진 선택" 창: 이미지·PDF·오피스 문서·HWP·전자책·압축 파일·글꼴·CAD·3D 모델은 지금 바로 변환, 동영상·오디오 등은 필요할 때 엔진 받음 → "나중에"
- 자동 변환 폴더: + 폴더 추가 → 감시할 폴더 → 프리셋 JPG → 감시 중. webp 2장 넣으니 converted 에 JPG 2장("2개 변환, 실패 없음"), 원본 그대로
- 프리셋 HWP + 워드 회의록(.docx) → converted 에 .hwp. 그 HWP 를 TXT·PNG 로 다시 바꿔 내용 그대로인 것 확인
- 홈: 최근 변환 목록 + 파일 열기·폴더 열기·되돌리기 버튼 (되돌리기는 눌러 보지 않음)
- 원형 툴바 설정 화면 HWP/HWPX 바퀴(PDF·DOCX·HWPX·HWP·PNG·TXT) 봄. Ctrl 끌기는 설명서 기준(직접 안 해 봄)
- README "Nothing is uploaded. Filee works offline" → 출처 밝혀서만 씀. 인터넷 끊고 시험은 안 함
- 써 보지 않은 것: 동영상·오디오 변환, OCR, 엔진 설치, 되돌리기 실행
- 무료 · MIT, 윈도우 10·11 · 맥(미리보기) · 리눅스(README), 메뉴 한국어. 깃허브 KnifeLemon/Filee 별 28,793(11/19)
