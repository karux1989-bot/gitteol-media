# Filee 1분 세팅 가이드

📅 깃털랩이 직접 써 보고 정리했어요. (2026년 11월 19일, 윈도우 PC · 시험용으로 만든 가짜 파일 "주간 회의 정리" 회의록과 webp 사진)

## ⏱ 30초 요약
- 파일을 다른 형식으로 바꿔 주는 무료 변환 앱이에요
- 폴더 하나를 정해 두면, 거기 넣은 파일이 자동으로 바뀌어요 (webp → JPG)
- 워드 파일(.docx)을 한글 파일(.hwp)로도 바꿔요
- 무료 · MIT 라이선스 · 메뉴 한국어 · 깃허브 별 28,793(11/19 확인)

## 📲 설치
| 항목 | 내용 |
|---|---|
| 윈도우 (winget) | winget install --id KnifeLemon.Filee |
| 깃허브 Releases | 설치 파일 또는 휴대용(Portable) zip |
| 버전 | 2.5.0 |
| 지원 OS | 윈도우 10·11 · 맥(미리보기) · 리눅스 (설명서 기준) |

- 깃털랩은 휴대용 zip 으로 시험했어요 (공식 SHA256 값과 일치 확인)
- winget 은 목록에 있는 것까지만 확인했어요. 설치할 때 관리자 권한 창이 떠요
- 깃허브: https://github.com/KnifeLemon/Filee

## 🚀 1분 따라 하기
1. 첫 실행 — "변환 엔진 선택" 창이 떠요. 이미지·PDF·오피스 문서·HWP·전자책·압축 파일·글꼴·CAD·3D 모델은 지금 바로 변환된다고 나와요. "나중에"를 눌러 넘어가면 돼요
2. 자동 변환 폴더 만들기 — 왼쪽 "자동 변환 폴더" → "+ 폴더 추가" → 감시할 폴더 경로를 넣어요
3. 형식 고르기 — "변환할 프리셋"을 JPG 로 골라요. "감시 중"이 켜져 있는지 봐요
4. 파일 넣기 — 그 폴더에 webp 사진을 넣으면, 폴더 안 converted 폴더에 JPG 가 생겨요. 원본은 그대로 남아요 (깃털랩 시험: 2개 변환, 실패 없음)
5. 워드 → 한글(HWP) — 프리셋을 HWP 로 바꾸고 워드 파일(.docx)을 넣으면 converted 폴더에 .hwp 가 생겨요
6. 최근 변환 기록 — 홈 화면에 바꾼 기록이 남아요. 기록마다 파일 열기 · 폴더 열기 · 되돌리기 버튼이 있어요

## ✍️ 깃털랩이 해 본 것
| 넣은 파일 | 프리셋 | 결과 |
|---|---|---|
| webp 사진 2장 | JPG | JPG 2장 (2개 변환, 실패 없음) |
| 워드 회의록 meeting_notes.docx | HWP | meeting_notes.hwp |

- 만든 HWP 를 다시 TXT·PNG 로 바꿔 보니, 회의록 내용("주간 회의 정리" …)이 그대로였어요
- 위 파일은 모두 시험용으로 만든 가짜 파일이에요

## ⚠️ 참고
- 설명서(README)에 따르면 탐색기에서 Ctrl 키를 누른 채 파일을 끌면 커서 옆에 형식 바퀴(원형 툴바)가 떠요. 깃털랩은 설정 화면에서 HWP/HWPX 바퀴(PDF·DOCX·HWPX·HWP·PNG·TXT)만 봤고, Ctrl 끌기는 직접 해 보지 않았어요
- 동영상·오디오 변환은 엔진을 따로 받아야 해요. 깃털랩은 엔진 설치와 동영상·오디오 변환은 해 보지 않았어요
- 설명서(README)에는 파일을 어디에도 올리지 않는다고 적혀 있어요. 깃털랩이 인터넷을 끊고 따로 시험하지는 않았어요
- 되돌리기 버튼은 있는 것만 확인했고, 눌러 보지는 않았어요
